# 内存预算与资源生命周期

目标 ESP32-C3 没有 PSRAM，内部 RAM 需容纳显示、LVGL、任务栈、Wi-Fi/TLS、
目录和活动解码器。空闲总堆、最大连续块和栈水位是不同指标。

## 当前分配预算

| 资源 | 预算与持有者 |
| --- | --- |
| LVGL | 固定 28 KiB 池，仅创建当前页面所需控件 |
| LCD 传输 | 单个 20 行 RGB565 DMA 缓冲：9,600 字节 |
| I2S | 播放仅 TX，六段各 240 帧 DMA，初始化双声道 16 位时共 5,760 字节 |
| 音频任务 | HTTP 栈 6 KiB，解码栈 8 KiB |
| 应用任务 | 6 KiB 栈 |
| 目录任务 | 临时 10 KiB 栈，挂起后由外部删除 |
| 压缩音频 FIFO | 12 KiB，首次预填充 8 KiB |
| 解码输入 / PCM | 输入 3 KiB，PCM 初始 4,608 字节，仅必要时增长至 8 KiB |
| HTTP | 网络临时 1 KiB，RX/TX 各 1 KiB |
| TLS | 动态入站 16 KiB、出站 4 KiB 记录缓冲 |
| 目录 | 每频道最多 100 条 Flash 记录，RAM 为四条分页窗口与一份播放快照；压缩章节最多 80 条 / 6 KiB |
| 历史进度 | 32 个固定 NVS 键，每条 64 字节（有效载荷 2,048 字节，另有 NVS 开销）；逐条扫描 |
| 解码器准入 | MP3：64 KiB 空闲内部堆；AAC、M4A、WAV：80 KiB |

预算不包括分配器开销、驱动描述符、socket、协议状态和解码及解析分配。
固定 LVGL 池的空闲空间不会返回系统堆。字体和美术为 Flash 映射常量，不能把
其文件大小视作帧缓存 RAM。

## 持有者与并发

三个动态中文字号每库严格保留 8,105 个规范汉字和 512 个非汉字，仍用不压缩的
2-bpp 位图，因此字符精简不增加解压工作。范围外字符使用可见替代字，规范表中的
补充平面字符也保留。首页与设置只共享顶栏美术，中间背景为纯黑。

3 MiB 目录分区每频道有两个固定缓存区。流式 RSS 更新逐条写入，校验 CRC，最后
提交头部；未完成的更新保留旧缓存区，旧缓存区只在复用时擦除，容量不会随更新次数
增长。每频道最多接收 100 个有效节目，响应预算为 2 MiB；这不保证每个 RSS 都提供
100 期节目。

目录更新在建立 TLS 连接前一次性预留约 25 KiB 的有界节目缓冲，联网后只解析
需要写入 Flash 记录的字段，跳过节目正文、作者、日期和封面等未使用元数据。
因此缓冲不会在 TLS 活动期间扩容，RSS 返回 5 期或 100 期时的联网分配峰值相同。
目录与章节联网任务要求至少 80 KiB 空闲堆和 32 KiB 最大连续块；不足时返回可恢复
的低内存错误并保留旧目录，不触发异常重启。

逐节目进度使用独立的有界 NVS 映射，避免每分钟保存时重写整个目录缓存区。
频道和 GUID 经 SHA-256 识别；紧凑记录保存进度、时长、完成标志、保存序号及 CRC。
内容不变则不写 Flash，NVS 在固定分区内回收旧数据，满 32 条时变化的保存替换
最旧记录。不存在无限追加历史或随节目数增长的堆集合。独立的上次播放快照保留
可播放地址与标题，即使节目已从 RSS 淘汰；没有逐节目记录时导入旧快照的进度。

- 播放器仅初始化 I2S TX，不分配闲置 RX DMA；BSP 的独立全双工 API 仍支持录音。
- 显示文字由 LVGL 持有，同文字更新保留滚动位置；控件和底栏随页面释放。
  只读字体描述直接引用，仅修改 fallback 的字体复制描述。
- RSS 在消费缓冲前借用有边界的节目、标签和 CDATA 视图；保存字段自有数据。
  目录更新跳过未使用的大正文，章节时间轴需要时仍使用完整解析。实体名称表为只读常量。
- 目录仅保留显示与播放元数据及压缩章节，刷新失败保留可用列表和缓存。
- 目录操作按需协调或停止音频。应用等目录任务挂起后同步删除，再执行解码准入；
  任务自行删除会等空闲任务才回收栈。
- 停止、换节目或定位先取消旧 HTTP generation 再重置 FIFO，旧生产者不能写入新流。

## 安全余量

不能因为单个 MP3 通过就缩减 TLS 记录、输出 DMA、FIFO 或任务栈。需覆盖支持
格式及最坏 TLS、重定向和解析调用链。即使总堆够用，最大连续块也必须足够。
MP3 准入保持保守，低内存明确失败。

在状态切换时测量内部空闲、历史最少、最大连续堆与各任务自身栈水位；数字日志
不含 URL 和凭据。编译尺寸报告描述静态 DRAM，原生渲染描述固定池，不能等同
目标设备分配器测量。

见[音频生命周期](gcores-audio.zh_CN.md)与[验证](gcores-validation.zh_CN.md)。

## 已保存 WiFi 配置

WiFi 使用一份可替换的 220 字节 NVS 数据块保存一组或两组网络，第二组为可选。
配置表、当前配置与待保存的两组提交，共占 532 字节固定配置数据，另有少量连接状态
和计时字段。复用现有应用轮询与网络事件，不新建任务。管理页仅临时分配约 2 KiB
渲染空间，发送后释放，响应中不包含密码。导入旧 Flash 配置后，驱动配置改用 RAM
存储，切换尝试不反复写入凭据；正常重连且配置与优先级不变时不重写保存表。
离线重试从一分钟逐步退避到最多五分钟，连接正常时不周期扫描。当前固件配置未加密
保存的网络凭据。
