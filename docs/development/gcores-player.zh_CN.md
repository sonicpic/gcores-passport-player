# 使用手册

应用分为播客列表首页、播放页、设置页。首页五个标签对应机核游戏频道、机核生活
频道、机核兴趣频道、核市奇谭、银屏系漫游指南，每个在 Flash 中最多保留近期
100 期，滚动时 RAM 仅缓存四条。正在播放的节目超出列表时仍保留为普通节目行。上、下、OK
为可编程功能键，独立电源键为硬件控制，不是应用输入。

## Wi-Fi 配网

没有保存网络时，开机进入配网页。手机连接 `Gcores-Passport`，密码以设备屏幕
为准，浏览器打开 `http://192.168.4.1`。输入 2.4 GHz 网络名称与密码，点击
“保存并连接”。支持 WPA/WPA2 或开放网络，仅开放网络可留空密码；不支持企业网络。

成功后显示网络已连接并自动关闭热点；十分钟未完成会超时。失败时在配网页长按
下键重新打开热点，手机重新连接并提交正确内容。换网时，首页长按 OK 进入设置，
选择“Wi-Fi 配网”并按 OK。退出手动配网页也会关闭热点。最多记住两组网络，第二组为可选项；热点管理页一次可以填写并保存一组或两组。支持 UTF-8 中文网络名，
受 WiFi 32 字节的 SSID 上限限制，纯汉字通常最多十个。合法配置先保存再尝试连接，
不要求两组网络同时在附近。只提交一组时添加或更新并保留另一组；同时提交两组
则一起保存。相同 SSID 可更新密码，密码留空保留已存密码，勾选开放网络才移除
密码。单独保存第三组时替换最久未成功使用的一组。

开机优先尝试上次连接成功的网络，再尝试另一组。已保存网络都不可用时保持离线，
以逐步延长的间隔重试，不自动打开配网热点；连接正常时不周期扫描。
凭据存于设备，不嵌入
固件；当前配置未加密 NVS 凭据。

节目列表先显示缓存。网络和互联网时间就绪后，自动更新在音频未活动时按北京时间
自然日每天最多更新一次全部五个频道。全部成功的更新日期跨重启保存，时间未知时
延后自动更新；自动更新失败不会连续重试，仍可随时在设置手动重试。设置里的更新
同样逐个刷新全部频道。各频道独立提交，失败保留该频道
旧列表并继续更新其他频道。本地翻页不联网也不中断播放。手动刷新或读取章节
可能停止并恢复播放，以避免 TLS 与解码分配重叠。

## 按键

| 页面 | 短按上 / 下 | 长按上 / 下 | 短按 OK | 长按 OK |
| --- | --- | --- | --- | --- |
| 首页 | 选择节目 | 向左 / 向右切频道 | 播放或打开节目 | 设置 |
| 播放 | 增 / 减音量 | 预览后退 / 前进目标 | 播放 / 暂停 | 首页 |
| 设置 | 选择项目 | 无额外操作 | 调整或执行 | 首页 |
| Wi-Fi 配网 | 按屏幕提示操作 | 下键重开热点 | 返回并关闭热点 | 返回 |
| 按键帮助 | 阅读页面 | 无额外操作 | 按屏幕提示操作 | 返回 |

按住约 0.5 秒触发长按。首页频道首尾循环，每次长按切一次，浏览其他频道不停止
音频。当前播放或暂停的节目在列表中有状态标记，再次打开保留进度和暂停状态，
设置首项在本次开机已经打开播放内容后显示高亮的“回到当前播放”，直接打开现有
播放页并保留状态；仅有上次保存记录、尚未开始播放的开机状态不显示该项。

播放页按住时加速移动预览目标，松手仅提交一次定位。选定位置保留到对应请求
完成；暂停状态下定位仍保持暂停，直到明确继续。MP3 Range 定位为近似位置，
回退到顺序定位时可能等待更久。

进度每分钟、切换播放节目和深睡前保存，播完也会记录。选择其他节目时自动使用
该节目的保存位置，已播完节目从头开始。记录按频道和 GUID 关联，不绑定列表
序号或音频地址，因此 RSS 重排、地址变化不会丢失关联。最多保留最近保存的
32 期，容量满后发生变化的保存淘汰最旧记录。突然断电可能丢失上次成功保存后的进度。

任一页面双击 OK 息屏而不中断播放。任一功能键首次唤醒动作持续到松手均被消费，
不触发其他操作；唤醒恢复所选亮度。硬件电源键独立。

## 播放与设置

播放页显示标题、频道、当前和下一条章节文字、进度、已播时间和总时长。标题、
列表与章节超长文字自动滚动，息屏停止滚动。无时间轴时两个文字位置均显示
“暂无时间轴”，隐藏时间戳。加载状态不暴露内部读取步骤。

设置包含有内容时的回到当前播放、更新列表、Wi-Fi 配网、亮度、自动息屏、定时停止、立即息屏、停止并深睡
和按键帮助。

- 亮度：20/40/60/70/80/100%。
- 自动息屏：15/30/60/120/300 秒或常亮。
- 定时停止：关闭或 15/30/45/60 分钟。
- 息屏继续播放；停止并深睡保存进度并停止音频，功能键唤醒深睡会重启设备。

顶栏以图形填充显示音量和电量，电量无法读取时明确表示。公开硬件接口不提供
软件电源键或背面指示灯控制。
首页与设置中间区域为纯黑，保留共用顶栏与底栏美术。

## 固件安装

| 分区 | 偏移 | 大小 |
| --- | --- | --- |
| NVS | `0x9000` | `0x26000` |
| PHY | `0x2F000` | `0x1000` |
| Factory application | `0x30000` | `0x4D0000` |
| 目录缓存 | `0x500000` | `0x300000` |

分区适配 8 MB，无 OTA 槽。已验证合并镜像从 `0x0` 写入，可能重置设置与进度。
仅应用更新从 `0x30000` 写入，必须先确认分区表匹配；不需要常规整片擦除。
从旧的大应用分区首次升级，必须同时写入 `0x8000` 的匹配分区表和 `0x30000`
的缩小应用。NVS、PHY 偏移和大小不变，分段写入保留设置与上次播放快照；旧
五期 NVS 目录导入 Flash 缓存。烧录前识别实际设备端口。见[构建验证](gcores-validation.zh_CN.md)与
[烧录策略](engineering/firmware-layout.zh_CN.md)。

播放器使用网络音频，不支持 SD 或本地节目库。见[格式与定位限制](gcores-audio.zh_CN.md)。

### 设置入口与机核 FM

设置页最前方依次显示有内容时的“回到当前播放”和始终可选的“机核 FM”，两项使用统一尺寸的原图图标，其他设置项保持纯文字。选择 FM 后进入播放页并加入官方同步电台；短按上下调音量，OK 暂停，再按 OK 重新加入当前电台位置，长按 OK 返回首页。不显示进度条或节目时间轴，大标题显示当前节目，原时间轴区域显示单行滚动的下一节目标题与轻量装饰动态条；不提供长按定位、单集断点保存；息屏播放和定时停止仍保留。进入 FM 前保存上一集播客进度。

节目时间轴遇到临时读取失败会受限重试一次；返回当前节目时若缓存尚未就绪，会重新读取并保留播放进度和暂停状态。首个章节不是从零开始时，显示已有章节，避免误报暂无时间轴。
