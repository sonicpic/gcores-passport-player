# Gcores Passport visual assets

This directory contains reference artwork, extraction scripts, Flash-resident
RGB565 assets and native previews for the 240 × 320 portrait interface.
The UI implementation is [passport_ui.c](../../main/passport_ui.c).

## Current interface

The player preserves the supplied cover, character, dark texture, timeline
decoration and footer artwork. LVGL draws episode titles, channel names,
chapters, progress, volume and battery state over the plate. The common plate
has no baked footer controls; home and settings select their own footer crops.
Settings use text and separators without list badge artwork.

Home accents follow the browsed channel: game `#FF453A`, life `#51C878`,
interests `#FF922E`, Heshi `#4D9EFF` and Yinping `#AD78F5`. Selected tabs, channel
text, row outlines and the playing label use these colors. Other pages retain
their own palette.

Titles use Noto Sans CJK SC Black at 22 px, body text Bold at 16 px and chapters
Regular at 12 px. Overflow titles and chapter labels scroll through native
LVGL labels. Scrolling pauses while the display is off and resumes on wake;
unchanged text does not restart it. Missing chapter data is shown explicitly
as a no-timeline label, with timestamps hidden. See the
[font guide](../fonts/README.md) for coverage, generation and verification.

## Artwork sources and extraction

The supplied images are retained under [references/](references/).
[extract-player-background.py](extract-player-background.py) produces seven
PNG/RGB565 plates and crops in [extracted/](extracted/).

| Asset | Source | Processing |
| --- | --- | --- |
| Player plate | [style-07-player.png](references/style-07-player.png) | Clear mutable labels/status fields, resize to 240 × 320, apply shared header |
| Shared header | [style-08-home-footer.png](references/style-08-home-footer.png) | Clear mutable volume/battery values, resize, retain top 240 × 26 |
| Common plate | [style-07-player.png](references/style-07-player.png) | Sample dark texture and computer motif, apply brightness/mask processing and shared header |
| Home footer | [style-12-home-footer.png](references/style-12-home-footer.png) | Resize to 240 × 320, crop bottom 240 × 34 |
| Settings footer | [style-11-settings-footer.png](references/style-11-settings-footer.png) | Resize to 240 × 320, crop bottom 240 × 34 |
| Speaker, arrows and OK marks | [style-07-player.png](references/style-07-player.png) | Extract and resize to 12 × 12, 29 × 11 and 18 × 18 |

These seven assets contain 341,414 raw RGB565 pixel bytes. They are constant
Flash data and do not require a full-screen heap copy. The BSP's partial LCD
framebuffer is separate; linked Flash usage depends on retained assets.

[extract-reference-assets.py](extract-reference-assets.py) generates the
current 28 × 28 list badge from
[style-10-list-icon.png](references/style-10-list-icon.png), using source crop
`(125, 128, 1128, 1131)` and LANCZOS scaling. It also preserves exact source
crops and resized cover, character and waveform assets from
[style-02-player.png](references/style-02-player.png). The script records their
coordinates and sizes; these separate crops are not the current player plate.

From the repository root, with Python 3 and Pillow installed:

```powershell
python assets/gcores/extract-player-background.py
python assets/gcores/extract-reference-assets.py
```

## Native previews

[preview-lvgl.png](preview-lvgl.png) is the reproducible overview generated by
the [native renderer](host-render/). It compiles the actual UI, fonts and
assets against the locked LVGL component and applies the BSP's 30 px corner
mask. [player-reference-lvgl.png](player-reference-lvgl.png) and
[player-reference-comparison.png](player-reference-comparison.png) show the
player render and its comparison with the scaled source artwork.
[Community images](community/README.md) contain individual player, home and
settings frames.

Episode titles, chapter text and Wi-Fi data in the fixtures are synthetic.
These are software renders, not photographs or captures of the physical LCD.
They validate layout and glyph drawing; they do not validate LCD transfer,
color order, backlight or electrical behavior.

Resolve the project's ESP-IDF dependencies first so that
`managed_components/lvgl__lvgl` exists. With a native MinGW compiler on PATH,
CMake, Ninja, Python 3 and Pillow, run from the repository root:

```powershell
cmake -S assets/gcores/host-render -B assets/gcores/host-render/build -G Ninja
cmake --build assets/gcores/host-render/build -j 4
Push-Location assets/gcores/host-render
./build/passport_ui_host.exe
Pop-Location
python assets/gcores/render-lvgl-contact.py
python assets/gcores/compare-player-reference.py
python assets/fonts/verify-font.py
```

The renderer uses a 28 KiB LVGL pool. Its checks cover scrolling, display
off/wake, seek feedback, complete maximum-length UTF-8 strings, repeated page
creation/deletion, glyph drawing and allocator consistency. Native allocator
measurements are not total MCU SRAM usage or physical-device validation.

## Rights and licenses

The list badge uses `references/style-11-list-icon.png`, cropped to the rounded
tile and downsampled with Lanczos antialiasing to 28 × 28 RGB565 pixels. It
replaces the previous badge at the same coordinates and uses 1,568 Flash bytes
with no extra runtime image buffer. Reproduce it with `extract-reference-assets.py`.

Settings navigation artwork is retained in
`references/settings-return-source.png` and `references/settings-fm-source.png`.
Run `python assets/gcores/extract-settings-icons.py` with Pillow to reproduce
the transparent 24 × 24 crops in `extracted/`. Both icons use the supplied
white/orange artwork, have equal visible bounds, and are centered within the
32-pixel settings rows. The generated `passport_settings_icons.c` stores
3,456 bytes of RGB565 plus A8 pixels in Flash; it requires no whole-image
decompression allocation. Only the current-player and FM rows draw icons.
The FM player reuses the existing player plate, masks its fixed chapter axis,
and hides position/timeline controls rather than duplicating the background.
