# Community display images

| File | Native render source | Content |
| --- | --- | --- |
| [cover.png](cover.png) | `../host-render/player-reference.ppm` | Player |
| [library.png](library.png) | `../host-render/library.ppm` | Home/library |
| [settings.png](settings.png) | `../host-render/settings.ppm` | Settings |

All three files are 240 × 320 PNGs, portrait 3:4, showing complete UI frames
with the BSP's 30 px corner mask. They are native LVGL software renders with
illustrative episode and chapter text, not physical-device photographs or
LCD captures.

Artwork sources, extraction and font licenses are documented in the
[visual asset guide](../README.md).
