# 原图裁切素材

播放器封面、机器人、波形装饰直接裁自用户提供的
`../references/style-02-player.png`（1086 × 1448），不是生成变体或重新绘制的替代品。
源图 SHA-256 为
`816cdb0fa38f0eea333e42b756922af7b6065b6c16176e598204d04fec7f33e8`。

列表徽标单独裁自 `../references/style-10-list-icon.png`。

`*-source.png` 保留原分辨率下的完整裁片。设备 PNG 使用 Pillow `BOX` 确定性面积缩小（列表徽标采用 `LANCZOS`），
生成的 C 文件将 RGB565 像素作为常量存于 Flash，不需要 PNG 解码器、全屏帧缓存或生成的
透明蒙版。像素数据合计 31,596 字节；LVGL 图像控件及解码描述符仍计入实测 UI 池。
